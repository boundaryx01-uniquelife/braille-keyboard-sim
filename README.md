# 점자 키보드 제작기 (사이트)

시각장애인이 점 6개 키로 점자를 직접 치는 저가 오픈소스 점자 키보드(ESP32, 영어·한글)를 만들어 가는 과정을 정리한 정적 사이트입니다.

- `index.html` 처음 화면
- `simulator/` 브라우저에서 키를 눌러 보는 시뮬레이터 (펌웨어 규칙을 JS로 옮겨 돌립니다)
- `docs/` 제작 기록과 만드는 설명서

**알아 둘 것**
- 확인한 것은 모두 컴퓨터에서 자동 테스트로 확인한 것이고, 실물 하드웨어로 확인한 것은 아직 없습니다.
- 한글 점자 표는 2024 개정 한국 점자 규정 공식 예시와 대조했을 뿐, 점자 사용자·전문가의 확인을 받지 못했습니다.
- 이 저장소는 사이트 파일만 담고 있고, 펌웨어 등 소스 코드는 아직 공개하지 않았습니다.
- 라이선스를 정하지 않았습니다. 정해지기 전에는 복사·재배포 허락을 뜻하지 않습니다.
